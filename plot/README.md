# PreVision Figure Plot

This `plot` directory contains scripts producing figures for experiemtns.

## Prerequisites

- Please install Times New Roman font.
- Please install python packages using the below commands.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

- We ask reviewers to update `data.py` file. Please update values in the file to experiemnt results from your environment.


## How to Plot Figures


Run `gen_all.py` using below command to generate figures for experiments. 
The generated files will be placed in the `output` directory.

```bash
python gen_all.py
```
